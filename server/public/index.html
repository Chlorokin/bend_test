Activity

    Not proven (the limits)

    • That the model is TigerBeetle. The laws are about ledger.bend. That it matches the real database is only checked, one command at a time. Break the model shows it failing.
    • Time. The model has no clock. Hold expiry is a timer in the TypeScript shell, with TigerBeetle's own timeout as a backstop. A proof can say "an expired hold is never paid for", but not "a hold does expire".
    • The shell. server/*.ts encodes ids, sets flags, maps status codes and owns the sessions. None of that is checked. The panels on this side are rendered there; they call the proven escaper, but nothing forces them to.
    • Numbers. TigerBeetle counts in u128. Bend's runtime Nat stops at 248, so ids are small counters and prices are in cents.
    • The laws themselves. A proof shows the code meets the law as written. A wrong or missing law, like "refunds exist", is not caught.
    • The browser, the network, TigerBeetle's own code. These are trusted. TigerBeetle is tested with its own deterministic simulator, not proven.
